# Task 5 – Process Management in Linux

## Overview
Hands-on practice on managing Linux processes and system services using the command line.

## What I Did
- Listed running processes using `ps` and `top`
- Terminated processes using `kill` and `kill -9`
- Learned Linux process states
- Managed services using `systemctl`
- Enabled services at system boot
- Monitored CPU and memory usage

## Key Learnings
- Each process has a unique PID
- Difference between `kill` and `kill -9`
- Daemons run as background services
- High CPU usage impacts system performance
